## FL-C007 findings informing this request

Official sources place Moving under **Monitoring**, not **Licensing**. Municode Article VIII regulates estimates, contracts, disclosures, inventory, liability, and enforcement — **without creating a separate public mover license/registration/permit/roster**.

Public Accela Civic Platform complaint-history report (ConsumerProt reportID 31870) supports **name / partial-name** search and returns a PDF with:

RECORD ID · DATE OPENED · DATE CLOSED · BUSINESS NAME · ASSOCIATED NAMES · RECORD STATUS

A SAMPLE_ONLY partial-name search for “Moving” returned **24** business-level complaint rows where **RECORD STATUS** carries disposition-like official values (e.g., Resolved, No Compromise, Referred, Judicial System, Closed-Criminal, Closed: Resolved-Adjusted). Exact-name searches for some FDACS Pinellas movers returned empty reports (`NO_COMPLAINT_RECORD_RETURNED_FOR_SEARCH_WINDOW`).

This PRA therefore targets **structured bulk extracts and any internal regulated-business lists**, not a re-request of the public Accela name→PDF interface already sampled.

Preferred formats: **CSV, XLSX, JSON, or delimited text**.
