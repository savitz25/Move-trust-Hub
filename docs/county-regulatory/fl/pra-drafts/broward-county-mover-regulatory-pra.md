## FL-C004 findings informing this request

Official public materials confirm an active Broward mover registration + vehicle decal program, but **no public searchable/bulk roster** of registered movers was located (unlike Palm Beach County's Consumer Affairs API). ePermits A-Z lists Chauffeur Registration online but **does not** list Mover Registration as an online permit type. Consumer Affairs materials state consumers may **call** to determine current license status.

Therefore this PRA targets machine-readable extracts that are not practically available for self-serve download.

## Requested records (electronic / machine-readable preferred)

Preferred formats: **CSV, XLSX, JSON, or delimited text**.

### A. Current + historical mover registrations

Fields where maintained:

- registration / credential number  
- legal name / DBA  
- status (active/expired/suspended/revoked/denied/etc.)  
- issue / renewal / expiration dates (program expires Sep 30 annually)  
- business / mailing addresses  
- phone / email  
- owners / partners / directors / officers (business identity)  
- prior mover businesses (5-year disclosure if retained)  
- **FDACS IM / state Movers License number if stored**  
- local business tax identifiers if linked  

Include historical roster(s) for the last 5–10 years if available.

### B. Vehicle permits / decals

- parent mover registration ID  
- vehicle/decal / permit identifier  
- VIN / tag where maintained as public regulatory record  
- vehicle gross weight  
- vehicle status (active/inactive)  
- permit/decal issue and expiration dates  

### C. Consumer complaints (business-level only)

- respondent / business  
- mover credential ID  
- case / complaint number  
- filing date / closed date  
- category / allegation  
- status  
- disposition / resolution / outcome  
- restitution / referral / enforcement escalation if tracked  

**Explicitly exclude consumer/complainant names, addresses, phones, emails, financial account numbers, and free-form narrative PII.**

### D. Enforcement / hearings / final actions

- citation / notice of violation / warning notice  
- case identifiers  
- hearing date / outcome  
- fine amounts  
- suspension / revocation  
- final disposition / final order  
- compliance result  

Please preserve distinction among allegation, notice, citation, hearing, and final action.

### E. Historical business identity (where available)

- prior names / DBAs  
- ownership / officer changes
