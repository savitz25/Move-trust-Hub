## Source composition (006A.1)

```text

coverage: data/*-county-assignments.ts  →  getStaticMoverCountyIndex()
overlay:  seedCompanies HQ/services + seedAutoTransportCompanies (slug-deduped)
```

**Precedence:** active-directory row wins identity; seed enriches HQ / services / entityType when slug matches; auto-transport seeds missing from catalog are appended deterministically by slug sort.

**No:** DB writes, Places, geocoding, LLM, new enrichment.

## Eligibility predicate (fail-closed)

AND of:

1. `slug` present (URL-safe)
2. `name` present
3. Stable identity: USDOT ≥ 5 digits **or** canonical slug (`move:co-{slug}`)
4. `out_of_service !== true`
5. `authority_active !== false`
6. Geography: **physical USPS state** OR **≥1 structured coverage county**

Free-text headquarters state is **not** required when curated county coverage exists.

**Not used:** payment, premium, ratings, review volume, Trust Score, SEO indexability.

## Identity mapping

```text
unique USDOT     → move:usdot-{digits}
shared USDOT     → move:usdot-{digits}--{slug}
no USDOT         → move:co-{slug}
```

Never uses company display name as identity.

### Continuity vs v1

Compared on the **full eligible set** (not truncated pilot).

- Exact ID matches preserved for overlapping slugs with correct USDOT.
- **Authoritative corrections** when v1 incorrectly shared Mayflower USDOT `125563` (and similar) across brands via `--slug` collisions. Catalog/seed restore brand-correct unique USDOTs.
- **Graebel:** seed intentionally leaves USDOT empty (agent network — must not stamp Mayflower authority) → `move:co-graebel-van-lines`.

## Geography / service area

**Physical location** (`city` / `state` / `zip` on the entity): seed HQ when parseable; else non-street city + headquartersState; else parseable city field. Never invented from county coverage.

**Service areas:** structured `coverageCounties` / county assignments → `{ kind: 'county', county: 'Monmouth County', state: 'NJ' }` plus derived state areas. Optional HQ city kind is a locality hint, not verified county coverage.

**ZIP rule:** physical ZIP ≠ service ZIP. Move has no ZIP-level service coverage in this offline graph.

### Keansburg / Monmouth / 07734 product rule (for Ask later)

- Exact city `Keansburg`: **not** in source → 0 exact matches.
- ZIP `07734`: **not** present as physical or service ZIP.
- **Monmouth County, NJ** assignments **are** present and exported.
- Ask ranking may treat **county service-area match as sufficient** for city-in-county queries (Keansburg ∈ Monmouth). This publisher does **not** fabricate a Keansburg city service area.

## Cohort algorithm

1. Load catalog + coverage + overlays.
2. Evaluate eligibility.
3. Map → NetworkDiscoveryEntity.
4. If eligible ≤ 200: sort by `network_entity_id`, take all.
5. If eligible > 200: **stratified round-robin by `entity_type`** (types sorted A–Z; within type by ID) until 200 — avoids lexical `move:co-*` starving `move:usdot-*`.
6. Final export sorted by `network_entity_id`.

No payment / premium / ratings / Trust Score selection signals.
